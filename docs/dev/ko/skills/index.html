스킬 카탈로그

npm 패키지는 감사된 핵심 스킬 8개만 기본 제공합니다. 이 페이지의 이름과 카테고리는 skills_ref/registry.json과 일치합니다. 추가 스킬은 설치된 Codex 환경 또는 사용자가 명시적으로 설정한 신뢰 저장소에서 가져온 뒤에만 나타납니다. 실제 설치 목록은 weasley-podex skill list로 확인하세요.

자연어 사용: “스킬 목록 보여줘”, “browser 스킬 정보 보여줘”, “goal 스킬 켜줘”처럼 요청할 수 있습니다. 슬래시 명령은 /skill list입니다.

기본 제공 8개 스킬을 이름·설명·카테고리로 검색할 수 있습니다.

스킬 설치 및 관리

로컬 작업에는 실제 기본 제공 이름을 사용하세요:

weasley-podex skill info browser
weasley-podex skill install goal
weasley-podex skill list

가져온 스킬

추가 스킬은 설치된 Codex 환경에서 발견되거나 신뢰하는 Git 저장소를 명시적으로 설정한 뒤에만 나타납니다. 가져온 이름은 기본 제공 기능으로 간주하지 않습니다.

export WEASLEY_PODEX_SKILLS_REPO=https://github.com/your-org/trusted-skills.git
weasley-podex skill reset
weasley-podex skill install imported-skill-name
weasley-podex skill info imported-skill-name
신뢰 경계: 지침을 검토한 저장소만 설정하세요. 설치된 Codex 카탈로그와 WEASLEY_PODEX_SKILLS_REPO가 모두 없으면 reset은 이 8개만 사용하며 원격 스킬을 가져오지 않습니다.

커스텀 스킬 만들기

스킬 디렉토리를 생성하여 자체 도메인 지식을 추가할 수 있습니다:

mkdir -p ~/.weasley/podex/skills/my-company
cat > ~/.weasley/podex/skills/my-company/SKILL.md << 'EOF'
# My Company Standards

Internal coding standards and domain knowledge.

## When to Use

Trigger when working on any project in ~/work/ directory.

## Rules

1. Use pnpm instead of npm.
2. All APIs must follow our internal OpenAPI spec.
3. Database migrations use Drizzle ORM.

## Templates

```typescript
// Standard API response format
interface ApiResponse<T> {
  success: boolean;
  data: T;
  error?: string;
  timestamp: string;
}
```
EOF
채팅 내: "회사 코딩 표준 스킬 만들어줘" -- 에이전트가 자연어 설명으로부터 커스텀 스킬을 스캐폴딩할 수 있습니다.

스킬 파일 구조

모든 스킬은 최소한 SKILL.md 파일을 포함하는 디렉토리입니다. 복잡한 스킬은 레퍼런스 하위 디렉토리를 포함할 수 있습니다:

~/.weasley/podex/skills/imported-skill-name/
  SKILL.md              # Main skill prompt (injected into system prompt)
  references/
    react.md            # Deep guidance for React
    vue.md              # Deep guidance for Vue
    svelte.md           # Deep guidance for Svelte
    tailwind.md         # Tailwind-specific rules

SKILL.md는 오케스트레이터 역할을 합니다. 상위 수준 규칙을 포함하고, 더 깊은 맥락이 필요할 때 하위 파일을 참조합니다.
